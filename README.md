# Matsuribayashi (Rascunhos)

Rascunhos iniciais da tradução em Português Brasileiro de Higurashi no <span style="color:red">Na</span>ku Koro ni Hou - Cap. 8: Matsuribayashi pela Miracle Translations

[Repositório da tradução](https://github.com/Miracle-Translations/matsuribayashi/)

---

Todos os textos daqui podem (e provavelmente vão) mudar completamente.

Os números escritos representam as linhas onde o texto se encontra no script original.

Geralmente, o texto do rascunho ignora espaços no começo e no final da linha (e, às vezes, apenas as partes que mudam no texto são listadas).

> Dica: as cores da sintaxe de Lua funcionam bem com a formatação que eu uso

|                                 |                                                                    |
|---------------------------------|--------------------------------------------------------------------|
| [ingles] -> [portugues]         | apenas a parte que o texto muda                                    |
| //REVISAR                       | marcador que indica a necessidade de dar mais atenção a uma linha  |
| //JP                            | quero ver o texto em japonês antes de tentar traduzir              |
| //DEVENDO                       | preferi deixar a tradução dessa linha pra depois                   |
| [texto em inglês]               | traduzo essa parte depois/talvez eu tenha uma ideia melhor depois  |
| \\"                             | aspas visíveis no texto (igual no script original)                 |
